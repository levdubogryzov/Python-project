## О проекте

Я создаю проект на Python, который превращает работу алгоритмов в эстетичное видео с помощью библиотеки Manim.

Моя цель — сделать абстрактную логику кода наглядной и красивой, используя плавную анимацию, математические формулы LaTeX и динамическую камеру.

В рамках проекта я визуализирую две ключевые области компьютерных наук:

**1. Алгоритмы сортировки**
Я покажу внутреннюю механику упорядочивания данных на примере трех разных подходов:
- обмена элементов на расстоянии в сортировке Шелла,
- рекурсивного разделения массива в быстрой сортировке (Quick Sort),
- и иерархического объединения блоков в сортировке слиянием (Merge Sort).

**2. Алгоритмы поиска путей в графах**
Я визуализирую процесс нахождения кратчайших маршрутов:
- радиальное расширение области поиска в алгоритме Дейкстры,
- направленный поиск к конкретной цели в алгоритме A*,
- и итерационную проверку всех связей системы в алгоритме Беллмана-Форда.

Ссылка на репозиторий: https://github.com/levdubogryzov/Python-project

## Этапы разработки

### Итерация 1: Алгоритмическая база и система логических событий
На этом этапе я создаю вычислительное ядро проекта. Моя главная задача — написать алгоритмы так, чтобы они могли транслировать каждый свой шаг внешней системе.

*   **Реализация алгоритмического ядра.** Я пишу выбранные алгоритмы (сортировки и пути в графах) на чистом Python. Вместо обычного выполнения функции, я оформляю каждый алгоритм как генератор. Это позволит мне приостанавливать выполнение после каждого значимого действия — будь то сравнение чисел или обновление дистанции до узла графа.
*   **Разработка протокола событий.** Я создаю систему внутренних сигналов. Мой алгоритм будет не просто менять данные в памяти, а отправлять сообщение: тип действия, индексы задействованных элементов и их новые значения. Это отделит математическую логику от любого способа отображения.
*   **Валидатор логики.** Я создаю небольшой модуль для проверки корректности шагов. Прежде чем переходить к сложной графике, мне нужно убедиться, что поток событий точно отражает состояние данных и не содержит ошибок в последовательности операций.

### Итерация 2: Система трансляции в графику
Я пишу интерпретатор, который берет события из первой итерации и сопоставляет их с методами Manim. Например, сигнал о сравнении элементов я превращу в пульсацию объектов, а сигнал о перемещении — в плавную смену их координат на сцене.

*   **Математическое оформление через LaTeX.** Я добавляю на сцену слой текстовой информации. С помощью LaTeX я отрендерю формулы сложности и текущие значения переменных. Этот слой будет жить синхронно с графикой: когда мой алгоритм перейдет в новую ветку условий, текст на экране будет плавно меняться.
*   **Настройка режимов визуализации и экспорта.** Я реализую управление камерой и стилями. Сюда входит автоматическое масштабирование сцены под размер графа или массива, выбор цветовых палитр и финальная сборка видеофайла в нужном качестве через FFmpeg.

Используется библиотека Manim.

## Установка и запуск

### Вариант 1: Локальный запуск
1. **Системные зависимости**: Убедитесь, что в вашей системе установлены `FFmpeg` и пакеты `LaTeX` (необходимы для работы Manim).
2. **Установка зависимостей Python**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Запуск интерактивного меню**:
   ```bash
   python main.py
   ```
4. **Запуск автоматизированных тестов**:
   ```bash
   python -m pytest --cov=src test/
   ```
5. **Запуск профилирования производительности**:
   ```bash
   python -m profiling.profiling
   ```

### Вариант 2: Использование Docker
Контейнеризация позволяет запустить проект со всеми системными зависимостями без их ручной установки.
1. **Сборка образа**:
   ```bash
   docker-compose build
   ```
2. **Запуск приложения**:
   ```bash
   docker-compose run visualizer
   ```
3. **Запуск тестов внутри контейнера**:
   ```bash
   docker-compose run visualizer python -m pytest --cov=src test/
   ```
4. **Запуск профилирования внутри контейнера**:
   ```bash
   docker-compose run visualizer python -m profiling.profiling
   ```

## Использование
После запуска `main.py` (локально или через Docker) откроется интерактивное меню:
1. Выберите интересующий алгоритм из предложенного списка.
2. Программа выполнит алгоритм, проверит корректность результата через Validator и сохранит лог событий в папку `data/`.
3. При подтверждении запуска визуализации Manim отрендерит видеофайл на основе записанного лога.
4. Готовый видеофайл будет доступен в директории `media/`.
